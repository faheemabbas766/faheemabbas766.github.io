Hostel Manager — independent product

Built a Flutter/Firebase hostel operations system covering resident onboarding, room allocation and swaps, reservations, monthly fee ledgers, partial payments, checkout settlement and PDF records.

Engineering decisions

  • Provider for app state and repository classes for persistence and business operations.
  • Firestore transactions coordinate resident, room and financial record changes.
  • Checkout retry handling avoids releasing a bed twice or duplicating a checkout audit.
  • Owner/staff access rules and linked activity records support tenant isolation and accountability.
  • Integer fee calculations, proration and closed-period handling receive business-rule tests.

Verification

81 automated app tests passed locally on October 11, 2026, including finance, occupancy, checkout, PDF and UI scenarios. The existing app analyzer has 208 informational/style findings; no analyzer errors or warnings were reported in that run. Security-rule tests exist but are separate from this count.

Tradeoffs and remaining work

Private resident/client data and full application source are not published here. This is a code-backed case study, not a public production certification. Automated recovery, broader concurrency checks and device/provider testing remain work to complete. Repository transactions do not by themselves prove every multi-client race is resolved.

Public fee-ledger Cubit example

New standalone Dart engineering sample created in October 2026 with AI-assisted development and human review required before reuse. It demonstrates sealed loading/success/failure states, constructor-based repository injection, validation, integer money values and idempotent retry IDs. It is distinct from the Provider-based Hostel Manager production code.

10 tests pass; analyzer reports no issues. Tests cover partial payments, duplicate retries, conflicting payloads, invalid amounts, closed periods, network failure, concurrent actions and disposal. The adapter is in-memory and is not a production payment backend.
